01

擷取候選截圖

固定瀏覽器、字型、尺寸與資料，產生待驗收的網頁 PNG。

npm run capture
02

人工驗收並核准

回到 A 與 Figma 比對；確認後，將同一張候選圖明確保存為基準。

npm run approve -- --reviewed
03

每次修改，自動檢查

差異會讓測試失敗，交由人員確認。不會自動更新已核准基準。

npm test

開始一次可靠的比對
  1. 準備同尺寸圖片
    有匯出權限的 Figma Frame 匯出為 1× PNG；以相同視窗尺寸取得網頁截圖。長頁面請使用一致的完整頁面高度。
  2. 先看結構，再看細節
    並排確認整體；疊圖找位移；滑桿看同一區域；差異圖顯示像素色差。
  3. 只比較真正重要的區域
    框選表單或導覽列；忽略日期和姓名。可拖曳框選，也能用座標輸入。
  4. 人工核准後才建立基準
    像素比例不是設計還原度。確認視覺結果後保存網頁圖；到 B 下載自動回歸範本。
圖片只在這個分頁的記憶體中處理，不上傳、不寫入瀏覽器儲存空間。重新整理會清除圖片與設定。每張圖片最多 12 MB、12 百萬像素；合成畫布也受相同像素上限限制。建議使用 PNG 以避免壓縮雜訊。
